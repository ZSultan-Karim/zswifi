Installation Guide

Follow these steps to install ZS WiFi on your Windows computer.

1
Download ZS WiFi

Download the latest version from the official website.

2
Extract ZIP File

Extract all files into your preferred installation folder.

3
Run Setup

Double-click Setup.exe and follow the installation wizard.

4
Launch ZS WiFi

Open the application and configure your first MikroTik router.

System Requirements

Operating System Windows 10 / 11
RAM 4 GB or higher
Router MikroTik RouterOS v6 / v7
Database MySQL

MikroTik API Setup

Enable API Service using Winbox. 


/ip service

set api disabled=no

set api port=8728

Create Router

Open Router Manager then click Add Router.
